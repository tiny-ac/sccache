# REAPI (experimental)

sccache built with the `reapi` feature can use a REAPI v2.1 server for Rust compiles, set in `[dist.reapi]` (see [Configuration](Configuration.md)).

sccache connects to the server and hashes each toolchain's files once while it runs. The digests are kept in `<dist cache_dir>/reapi-digests.json`, so after a restart only changed files are hashed again. A Rust compile that misses sccache's cache is looked up in the server's action cache. On a hit, sccache writes its outputs and caches them as it would a local compile's. On a miss, with `on_miss = "execute"` (the default), sccache uploads the compile's inputs and toolchain to the server's CAS and runs it on a worker, and the server caches the result for every client. Execution needs a Linux client and a server that executes actions. Before a toolchain's first execution after sccache starts, sccache runs its `rustc -vV` on a worker. If the workers can't run it, for example on another CPU architecture, or it reports another commit hash than the local rustc, that toolchain's misses compile locally until sccache restarts, and its action cache lookups continue. A check that fails to reach a worker runs again at the next miss. With `on_miss = "local"`, a miss compiles locally and sccache never writes to the server. A compile that can't run through REAPI, or fails on a worker, runs locally with the arguments a REAPI worker uses, with a copy of the Rust sysroot under `<dist cache_dir>/reapi-sysroot-copies`, which is never removed. A compile that fails on a worker runs on a worker again, then locally, at every build. `SCCACHE_RECACHE` and `SCCACHE_NO_CACHE` skip the lookup. Each action carries the `salt` and the `platform` properties of `[dist.reapi]`, so clients with a different salt or platform don't share action cache entries. `sccache --show-stats` counts the action cache hits and the executions, and lists, by reason, the compiles that ran locally.

A failed connection is retried after 5 to 60 seconds, and a failed hashing of a toolchain after a minute. After 3 action cache lookups fail in a row, compiles skip the lookup for 5 seconds, doubling up to 60 while lookups keep failing. Executions pause the same way, and misses compile locally meanwhile. A server older than REAPI v2.1, or a server that refuses the credentials when sccache connects, isn't used until sccache restarts. A server that refuses them later, with UNAUTHENTICATED, or with PERMISSION_DENIED to a lookup or a download, is connected to again, and isn't used until sccache restarts if it refuses them again. A toolchain without rustc or std isn't used until it changes. A rustc whose `rustc -vV` prints `commit-hash: unknown` always compiles locally.
